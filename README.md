# Purple Portfolio Website

A clean, responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Customize it

### 1. Your name and bio
Open `index.html` and search for:
- `Your Name`
- `Developer · Gamer · Creator`
- `Write a short introduction`
- `Write your biography here`

Replace those with your information.

### 2. Your profile photo
Put your image in `assets/` and name it:

`profile.jpg`

### 3. Gallery
Add these images to `assets/`:
- `gallery-1.jpg`
- `gallery-2.jpg`
- `gallery-3.jpg`
- `gallery-4.jpg`

Or change the filenames in `index.html`.

### 4. Projects
Replace the project names, descriptions and links in the Projects section.

### 5. Social links
Replace the `#` links for Discord and Instagram with your real profile URLs.

### 6. Colors
Open `style.css`. The main purple colors are at the top:

`--purple`
`--purple-light`

Change those values to customize the theme.

## GitHub Pages

In your GitHub repository:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Your site will then be published through GitHub Pages.
